# ebook_bootcampdio
Sala em Fluxo – O Ecossistema Digital da Professora é um e-book desenvolvido para apresentar tecnologias digitais aplicadas à educação. O material aborda Inteligência Artificial, AVAs, ferramentas colaborativas, gamificação, automação, recursos multimídia e analytics, oferecendo exemplos práticos para a rotina docente.
